Case studies

Longer write-ups of things I’ve built. Each one covers the problem, what I did, the technical detail, what came of it and what I would do differently.

  • Detection Engineering

    Sigma Generator: Sigma rules drafted from MITRE ATT&CK

    An open-source tool I built that reads ATT&CK's detection analytics and drafts a Sigma rule for 556 techniques, grades every rule for quality, and refuses to write one when there is nothing concrete to match.

    556 of 697 active ATT&CK techniques get a drafted rule

    Deep dives into this project

    • Correlation rules for attack chains and thresholds
    • Threat group detection packs and SigmaHQ gap analysis
    • Hardening a local web UI against CSRF and DNS rebinding

  • Threat Intelligence

    IOC validation and STIX 2.1 automation at Seqrite Labs

    As a Threat Research Intern I built a pipeline that checks indicators against VirusTotal, AbuseIPDB, OTX and ThreatFox, automated STIX 2.1 bundle creation for OpenCTI, and modelled an APT28 tracking profile.
